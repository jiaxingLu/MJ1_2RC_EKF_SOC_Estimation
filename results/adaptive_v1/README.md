# Adaptive v1 validation evidence

This directory contains the reviewed public evidence for the adaptive estimator.

- `real_condition_matrix_reviewed.csv` — nine real-condition A/B cases with the reviewed numerical-equivalence verdict.
- `sensor_bias_closed_loop_stress.csv` — current- and voltage-offset stress cases.
- `adaptive_v1_verdict_summary.csv` — compact final architecture verdict.

Detailed methods, exact plots, and claim boundaries are documented in:

`docs/validation/adaptive_v1_validation.md`

The raw development logs, temporary OPE scripts, and working ZIP archives are intentionally not published in this directory.
